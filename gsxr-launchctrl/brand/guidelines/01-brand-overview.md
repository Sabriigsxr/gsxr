**GSXR LAUNCHCTRL**

| Trait            | Description                                             |
|-----------------|---------------------------------------------------------|
| Aggressive      | Bold, performance-first; zero tolerance for inefficiency |
| Controlled      | Precision over chaos; every action deliberate           |
| Mechanical      | Engineered like a track machine                         |
| Technical         | Deeply rooted in real engineering principles            |
| Premium          | High-quality materials, finishes, and experience         |
| Independent      | For builders who push limits alone or in small teams    |

### 1.4 Audience Personas

| Persona              | Characteristics                                                              |
|---------------------|------------------------------------------------------------------------------|
| **Terminal Native**  | Power user, shell-first workflow, values speed and customization            |
| **AI Tooling Builder**| Builds/integrates agent systems, MCP servers, local-LLM orchestration       |
| **Performance Dev**  | Works on latency-sensitive systems, cares about resource efficiency          |
| **Automotive Enthusiast**| Rider or track-day participant; appreciates mechanical precision         |

### 1.5 Positioning

> GSXR LAUNCHCTRL is a performance-focused AI coding-agent CLI. It gives developers
> a deliberate, coordinated, and controllable workflow: plan the mission, select the
> right model and tools, organize multiple agents, and execute with full visibility.

**Do NOT imply** the software controls real vehicles or performs ECU tuning. The
automotive identity is purely creative direction for a developer tool.

## 2. Usage Rules

- Black and blue are the primary palette
- Red is a restrained accent — like a tachometer entering the redline
- White/silver for text hierarchy on dark backgrounds
- Never place Racing Blue (#087BFF) on Carbon Black (#111722) — insufficient contrast
- All animations disableable via `prefers-reduced-motion`
- Logo minimum readable size: 24px height for horizontal wordmark

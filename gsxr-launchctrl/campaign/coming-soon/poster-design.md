### Layout Instructions

1. Background: Hero image with overlay at 70% opacity
2. Center overlay panel: dark gradient with 60% opacity
3. Text centered with 64px padding on all sides
4. Redline accent: thin horizontal line (#FF3048) above "COMING SOON"
5. X signature in wordmark glows with electric cyan (#21C8FF)

### Production Notes

- Generate background image FIRST (Asset 7: coming-soon-poster-clean-bg-for-text.jpg)
- Add all text in post-production design editor
- Export final as PNG at 1080×1350px for social, and as PDF for print
